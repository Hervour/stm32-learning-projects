# STM32 Learning Projects

STM32CubeMX / Keil MDK projects used for embedded-system learning.

## Projects

- `led-display-basic`: STM32F407 LED, key, LCD, ADC/DAC, timers, UART and related peripherals.
- `led-display-advanced`: expanded STM32F407 display and peripheral application.
- `fingerprint-lock`: STM32 fingerprint-lock demo using AS608 and software I2C modules.

Generated object files, listings, and firmware binaries are intentionally excluded; rebuild from the provided project files.
